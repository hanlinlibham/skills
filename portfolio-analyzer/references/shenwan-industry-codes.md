## Wind 批量查询示例

```python
from wind_client import WindClient

wc = WindClient()

# 获取所有行业指数当日收益率
codes = ",".join(SHENWAN_L1_CODES)
df = wc.wss(codes, "pct_chg", "tradeDate=20260227")

# 获取行业指数历史收盘价（用于计算区间收益）
df = wc.wsd(codes, "close", "2026-01-01", "2026-02-27")

# 获取行业指数区间涨跌幅
df = wc.wss(codes, "pct_chg_per", "startDate=20260101;endDate=20260227")
```
