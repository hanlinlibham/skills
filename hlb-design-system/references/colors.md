# HLB_ 色彩体系

## 浅色模式（标准色板 v2 · 2026-07-04）

> 浅色页面的**唯一标准色板**，取自 ablemind gov-review 设计语言
> （权威源链：ablework `globals.css` → `yangnan/ablethree/UI_SPEC.md` → 本节快照）。
> HLB_ 语言三件套**不变**：等宽字体、零圆角、编号分区、accent 每产品一色——只换色板。
> HSL 为权威表述（便于透明度派生），hex 为等值换算。

### 背景与文字

| token | HSL | HEX | 用途 |
|------|-----|-----|------|
| `--bg` | `40 27% 96%` | `#F8F6F2` | 页面底（暖米白，非纯白） |
| `--surface-1` | `0 0% 100%` | `#FFFFFF` | 卡片/区块（比 bg 亮，浅色下卡片是浮起的白） |
| `--surface-2` | `40 24% 92%` | `#EFECE6` | 嵌套区块 / 弱底 |
| `--text-primary` | `220 25% 15%` | `#1D2330` | 标题、正文（冷蓝黑） |
| `--text-secondary` | `220 12% 39%` | `#585F6F` | 副标题、描述 |
| `--text-muted` | `220 8% 58%` | `#8B919C` | 导航链接、表头、标签 |
| `--border` | `35 22% 78%` | `#D3C9BB` | 主边框（暖石灰） |
| `--border-l2` | `35 18% 86%` | `#E2DCD5` | 细分隔线 |

阴影仅一档：`0 1px 2px hsl(0 0% 0% / .05)`——分层靠边框与背景阶梯，不靠投影。

### 默认 accent（浅色）

浅色下产品 accent 若无特殊指定，默认政务深蓝 `--accent: hsl(212 53% 28%)` / `#22456D`
（hover `212 53% 22%` / `#1A3656`）。高饱和霓虹色（橙/青）在暖白底上对比不足，
浅色页面使用前必须验对比度 ≥3:1。

| error | `0 67% 46%` / `#C42727` | `0 70% 96%` / `#FCEEEE` |

## 基础色板

### 背景层级

| 层级 | 用途 | 通用值 | 说明 |
|------|------|--------|------|
| Base | 页面背景 | `#0A0A0A` / `rgb(10,10,10)` | 近纯黑，不使用 `#000` |
| Nav | 导航栏背景 | `rgba(10,10,10, 0.85~0.88)` | 半透明模糊背景 |
| Surface-1 | 卡片/区块底色 | 随产品调整 | 比 base 亮一档 |
| Surface-2 | 嵌套区块底色 | 随产品调整 | 比 surface-1 亮一档 |

### 文字层级

| 层级 | 用途 | HEX | RGB |
|------|------|-----|-----|
| Primary | 标题、正文 | `#F0F0F0` | `rgb(240,240,240)` |
| Secondary | 副标题、描述段落 | `#B0B0B8` | `rgb(176,176,184)` |
| Muted | 导航链接、表头、标签文字 | `#858088` | `rgb(133,128,136)` |
| Subtle | 编号底色、弱化边框 | `#3A363E` | `rgb(58,54,62)` |

### 产品主题色 (Accent)

每个产品页面使用独立的主题色，贯穿整个页面的强调元素。

#### Homepage — 橙色系

```
--accent:    #FF5C00  / rgb(255, 92, 0)
--accent-10: rgba(255, 92, 0, 0.1)    /* 标签背景 */
--accent-25: rgba(255, 92, 0, 0.25)   /* 标签边框 */
--surface-1: #141414  / rgb(20, 20, 20)
--surface-2: #1E1E1E  / rgb(30, 30, 30)
```

色相倾向：中性灰（无冷暖偏移）

#### AbleMind — 红粉色系

```
--accent:    #FF4757  / rgb(255, 71, 87)
--accent-10: rgba(255, 71, 87, 0.1)
--accent-25: rgba(255, 71, 87, 0.25)
--surface-1: #131114  / rgb(19, 17, 20)
--surface-2: #1E1C20  / rgb(30, 28, 32)
```

色相倾向：偏紫（surface 的 B 通道略高于 R/G）

#### AbleFlow — 青蓝色系

```
--accent:    #00C8FF  / rgb(0, 200, 255)
--accent-10: rgba(0, 200, 255, 0.1)
--accent-25: rgba(0, 200, 255, 0.25)
--surface-1: #111318  / rgb(17, 19, 24)
--surface-2: #1C1E24  / rgb(28, 30, 36)
```

色相倾向：偏蓝（surface 的 B 通道明显高于 R/G）

### 新产品主题色生成规则

1. 选择一个饱和度高的主色 (HSL saturation > 80%)
2. `--accent-10`: 主色 + `opacity: 0.1`
3. `--accent-25`: 主色 + `opacity: 0.25`
4. `--surface-1`: 在 `#141414` 基础上，向主色色相偏移 2~4 点
5. `--surface-2`: 在 `#1E1E1E` 基础上，向主色色相偏移 2~4 点
